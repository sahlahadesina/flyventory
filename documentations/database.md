## Explanation 
Preconditions: 

- 1)	Each asset has its own unique barcode 
- 2)	When an asset is scanned, it takes that and prints it into the asset ID. There is a different product ID, and the product ID increments the count of products. 
- 3)	Everything in the database is already stored, the barcodes only do matching.
